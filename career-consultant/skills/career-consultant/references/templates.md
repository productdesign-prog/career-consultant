# Working-file templates

Fill these from the intake interview. Keep them tool-agnostic. Use `[VERIFY]` for facts to double-check and `[NEED DATA]` for missing numbers/evidence — never invent.

## master_profile.md
```
# Master Profile — [Name]
Updated: [date]

## Basics
- Location: [city, country]
- Work authorization: [where]
- Relocation: [yes/no/where]
- Contacts: [email, links]
- Portfolio: [url]

## Target roles
- [role(s)]
- Level: [middle/senior/lead/head/principal]

## Geo & format
- [geographies]; relocation: [...]
- Format: remote / hybrid / onsite

## Languages
- [language — level]   # flag if a target market needs higher

## Constraints (hard-stop)
- Salary floor: [amount]
- Excluded industries/companies: [...]
- Other non-negotiables: [...]

## Experience (summary)
- [company — role — dates — one line]

## Positioning (working hypothesis)
- [one paragraph]
```

## achievements.md
```
# Achievements — confirmed
Markers: [VERIFY] = recheck accuracy; [NEED DATA] = no source/number.

## [Company / project]
- [Did X for Y, using Z, resulting in outcome]  [VERIFY/NEED DATA as needed]

## Claimable honestly
[skills]

## Claim with care / weaker
[skills + reason]
```

## skills_allowed.md / skills_restricted.md
```
# Allowed
[skills the person can defend]

# Restricted / mark as weak
[skills to avoid claiming, or to flag as basic]
```
